# Advanced Fluid Dynamics Design
## A Project-Based Learning course focused to the design of an axial fan

This is the repository of the course "Advanced Fluid Dynamics Design" of 
the Master Degree in Industrial Engineering (Mechanical) in the Higher
School of Industrial, Aeronautics and Audiovisual Engineering 
in Terrassa ([ESEIAAT](https://eseiaat.upc.edu/en))

This course is based on the design project of an axial fan.
